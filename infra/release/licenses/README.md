# License materials

This directory is the release location for product notices, third-party notices, and customer license terms.

- `TAROAI-NOTICE.txt` identifies the delivered product and the source of authoritative customer terms.
- Image SBOMs under `../sbom/` are the input for third-party license review.
- A release owner must attach the approved customer license document and generated third-party attribution report before external delivery when the commercial agreement requires them.

No private signing key, license activation secret, customer entitlement, or provider credential belongs in this directory.
