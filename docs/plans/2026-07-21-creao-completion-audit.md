## 2026-07-22 当前增量结论

- 核心 Chat 不再把 Web、Sandbox 和格式细则在 System Prompt 中重复一遍，工具说明和 JSON Schema 继续作为唯一工具契约。同一全新账号、同一 GLM 4.5 Flash 和同一“两句话解释海水为什么是咸的”问题，修复前 25 秒且只输出一句，修复后 5.9 秒严格输出两句；首轮模型输入从 2,993 字符降到 1,392 字符。
- Web 主链不再被人工截止为“1 次 Search + 1 次 Fetch”：模型最多可做 2 次不同 Search 和 2 次不同 Fetch，已成功的同参数调用仍由现有去重逻辑拦截。Tavily 每次固定返回最多 5 条，“当前/最新”查询的工具契约要求携带系统当前日期。真实复现发现 Tavily Extract 携带完整用户问题时会把 Python 下载页切到 2018 年的 `3.6.x` 历史片段；现保留兼容输入但不再把 `query/chunks_per_source` 交给 Extract，直接读取原页面。最终镜像下两次相同版本题均执行 `search → fetch`，分别 27.2 秒和 35.4 秒，严格返回 `3.14.6` 与官网链接；显式 URL 则无需先 Search，单次 Fetch 17.2 秒得到同一结果。
- 最新干净账号四类 Chat 复测：两句话直答约 5 秒且正确；缺城市天气约 6 秒追问，但 GLM 4.5 Flash 仍输出普通文本而未调用 `request_user_input`；补充“北京”后只做 1 次 Web Search、返回 5 条结果，Thought 18 秒并成功给出带来源天气。修复前同一链路连续搜索 2 次、第三轮输入膨胀到 20,259 字符并被供应商误报 `sensitive`；现在带工具的模型请求统一温度 0、Search 收敛为 5 条，安全误判消失。明确 Python 计算原本正确返回 `9592`，但总计 53 秒中约 44 秒是两轮模型等待；Sandbox 工具现允许模型显式声明短 stdout 就是最终答案，真实复测由 2 次模型降为 1 次，E2B 执行 2.93 秒、Run 总计 28.13 秒，仍严格返回 `9592`。更强智谱型号当前均返回 `429/1113`，不能用未开通模型掩盖延迟与函数调用差距。
- 明确要求 Python 计算的真实浏览器链路只执行 1 次 E2B `sandbox.command`，26.1 秒严格返回 `1098916481741`，与本地复算一致；整页刷新后 `Ran code / Completed`、Thought 与答案均完整恢复，Console 0 error。0 工具普通问答、Web、E2B 和恢复四条用户可见主链本轮均通过。

## 当前验收边界

- 按用户要求使用 Tavily 和 E2B；本地浏览器与本地进程沙盒不作为当前主路径。
- Release Compose 与该边界一致：默认 E2B、Browser disabled；自托管沙盒和 Browser Controller 仅在显式 profile 下启动。
- Browser Provider 关闭时不展示 Browser use，避免把未配置能力伪装成可用功能。
- 不为对齐接口名称新增重复 API；现有 Thread/Run/Agent 资源能够表达同一业务语义即可。
- 计费、SCIM、灾备等控制面能力不阻塞聊天主链；公共 Store / Discover 属于可见产品差距，但必须基于独立公共目录与审核契约实现，不能复用租户私有数据冒充。

## 剩余发布门槛

1. 正式部署配置 AWS Secrets Manager 等外部后端；本地加密后端只支持共享卷上的单机 Compose。
2. 通用 HTTP 写入与跨 API 副本的 OAuth state/callback 已验证；正式部署仍需选择一个目标业务 SaaS（例如 Gmail、CRM 或 Issue Tracker），提供该供应商 OAuth Client 与测试账号，完成授权、字段映射和可回滚的持久写入验收。
3. 历史 CREAO 验收工作区已有 `57` 条 Thread 和 `2` 个 Agent；本轮已用独立干净租户完成 0→1 Thread 的浏览器验收，后续自动验收应继续创建隔离租户，正式演示账号不要复用历史验收工作区。
4. 将当前大工作树按配置、后端、前端、迁移和测试分组审查；所有已暴露密钥在发布前轮换。
5. 当前 Grok 外部事实查询已由基线 46.39 秒、3 次模型调用收敛到 30.69 秒、2 次模型调用；同一版代码也观察到一次 113.13 秒的供应商长尾。统一镜像部署后的最小 Chat 只调用一次模型仍需 38.82 秒，平方和需 84.31 秒；绕过 Taroai 的原始 Grok 流式请求首字 74.64 秒、总计 76.71 秒，显式传 `reasoning_effort=none` 又在 90 秒超时，证明主要等待不在 Agent loop。显式读页历史为 69.13–70.47 秒，一次 Search + Extract 的天气查询约 95 秒；显式 Skill 已从 51 秒降至 25.28 秒，自主 Skill 选择仍为 41 秒。最终 GLM 镜像的普通直答为 5.2 秒，E2B 为 24.3 秒，直接 Fetch 为 17.2 秒，两次相同 Search + Fetch 为 27.2/35.4 秒；结果均正确，但普通回答仍出现一次“两句话”只输出一句的格式偏差。没有跨模型静默回退：用户显式选择必须被尊重，默认模型切换需要明确接受速度与稳定性的取舍。
